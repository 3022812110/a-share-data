# 当前状态

最后更新：2026-07-17

## 已具备的能力

- 全市场股票快照、主要指数、涨跌分布、资金与行情异动展示。
- 数据健康检查、过期提示和按需后台补刷。
- 自选股、自然语言条件选股、个股多周期 K 线、技术指标、研究卡和基础回测。
- 模拟账户、持仓批次、费用、A 股 T+1、成交记录、交易计划和卖后复盘。
- AI 单股决策和候选推荐，并保存生成时的行情、账户与风险上下文。
- 市场极端风险和行情过期时的后端买入硬阻断。
- 基于账户权益的总仓位、单票仓位、止损和回撤诊断。
- AI 推荐后 1/3/5/10/20 个交易日收益、MFE、MAE、胜率与策略校准面板。
- AI 项目日志，可供新设备或新会话快速恢复项目上下文。

## 当前已验证结论

- 在极端弱势市场中，系统会把建议切换为暂停新增买入，并在模拟下单后端再次执行同一套风险检查。
- 推荐评价使用推荐时价格作为基准，并等待足够的后续交易日数据后再形成对应周期样本。
- 账户权益快照从功能启用后开始积累；历史不足时，回撤统计只表示当前已有样本，不能代替完整历史回撤。
- 腾讯全市场成交额字段和日线成交额字段存在单位差异，当前同步流程已显式完成万元到元的换算。
- 当前自动化验证覆盖 22 个 Python 测试；前端生产构建已通过。

## 已知限制与风险

- 推荐表现刚开始结构化积累时可能没有成熟样本，需要经过后续交易日才能判断策略质量。
- 当前候选排序仍主要依赖行情和技术面信号，行业轮动、基本面、公告事件和点时无未来数据尚不充分。
- 基础回测策略和成交假设较简单，尚不能代表真实可成交收益。
- 模拟成交目前以即时成交为主，缺少委托、部分成交、撤单、滑点和涨跌停排队等完整订单生命周期。
- 账户风险历史依赖本地数据库持续积累；仅拉取代码不会恢复未提交的 `data/market.db`。
- 公开行情源可能限流、延迟或改变字段语义，新增数据源或字段时需要补充契约测试。
- 前端生产构建的主 JavaScript 包超过 500 kB，功能不受影响，但后续应按功能区做懒加载和拆包。

## 下一步优先级

1. 持续积累推荐成熟样本，并按市场状态、信号类型和持有周期比较表现，淘汰长期负贡献规则。
2. 增加账户权益曲线、仓位变化、行业暴露和风险事件时间线，让复盘不依赖单次快照。
3. 改进回测真实性：交易日对齐、手续费、滑点、涨跌停、停牌、样本外区间和基准对比。
4. 增加模拟委托生命周期和未成交原因，避免把“发出指令”等同于“真实可成交”。
5. 建立数据字段契约和质量监控，优先覆盖金额单位、时间戳、复权口径和数据源切换。

## 数据与安全边界

- `data/market.db`、`.env.local` 和所有密钥留在本机，不提交。
- 需要跨设备恢复个人数据时，使用 `shared-state/market.snapshot` 的备份/恢复流程。
- 本项目输出是研究和模拟决策辅助，不是收益承诺，也不应自动操作真实证券账户。
