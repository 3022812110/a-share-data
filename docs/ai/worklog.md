# AI 工作日志

按日期倒序追加重要变更。每条只包含事实、行为影响和实际验证结果；个人数据和敏感凭据不进入日志。

## 2026-07-20：候选后台预验证与严格买入门槛

### 变更事实

- 新增 `strategy_candidate_validations`，持久化单个推荐候选的滚动样本外验证结果，并按 24 小时复用缓存。
- 新增候选预验证后台线程、运行进度 API 和补位式队列；先验证高排序候选，被阻断后只继续验证实际补位到推荐表格的未验证候选。
- 训练推荐和单股 AI 票据统一为严格门槛：只有跨窗口稳定且匹配当前市场状态的候选可以生成买入计划；观察、样本不足和未验证候选均转为 0 股观察。
- 推荐表现只登记真正的买入建议，不再把观察候选混入后续胜率和收益统计。
- AI 交易页新增后台验证进度、缓存数量和完成状态；观察候选显示禁用的观察按钮，不再暴露买入操作。

### 行为影响

- 页面可以先返回候选而不被历史日线计算阻塞，并在后台验证完成后自动刷新证据状态。
- 没有足够策略证据时，系统会明确保持空仓等待，而不是用“低置信”包装成可执行的小仓买入。
- 被淘汰候选造成的后排补位会继续接受验证，但不会一次性扫描全部市场候选。

### 验证

- Python unittest 共 42 项通过，新增覆盖观察项不生成仓位、不进入推荐表现、稳定证据保留买入计划、样本不足保持观察和预验证记录构建。
- 实际后台队列先验证 12 只，再按页面补位分批扩展到 21 只，所有任务完成且无记录错误；最终结果为 0 个买入、3 个观察，未验证展示项为 0。
- 最终推荐新增计划金额为 0，观察项推荐数量均为 0，最新推荐批次没有新增可跟踪买入明细，也没有产生模拟成交。
- Vite 生产构建和本地浏览器检查通过；页面正确显示 21 只缓存、100% 完成进度和禁用的观察按钮。

## 2026-07-20：市场状态分层与策略证据推荐门控

### 变更事实

- 新增 `market_index_daily_bars` 和上证指数历史日线缓存；实际同步得到 800 根指数日线。
- 新增上涨、震荡、下跌历史状态分类，使用窗口开始前的 20/60 日收益、均线方向和波动率，不读取窗口开始后的价格。
- 每个滚动样本外窗口新增市场状态标签，策略汇总新增分状态收益、超额、交易数和最差回撤，并展示历史适用状态。
- 稳定性股票池调整为保留当前持仓、自选、最近推荐和高流动性补充的配额，确保推荐候选可以进入后续验证闭环。
- AI 训练推荐和单股 AI 票据接入最新稳定性证据：稳定且状态匹配时加分，观察或样本不足时降权，失效或状态不匹配时阻断，未验证候选限制为低置信小仓训练。
- 推荐批次新增 `strategy_context_json`，持久化稳定性批次、当前市场映射、候选加分/降权/阻断统计和门控规则；风控策略版本更新为 `2026-07-20.v2`。

### 行为影响

- 系统可以区分“策略整体尚可”和“策略在当前市场状态下是否有效”，不再只看跨窗口平均值。
- 已明确失效或在当前状态下表现不匹配的股票不会进入买入推荐；未验证标的仍可用于模拟训练，但不能显示成策略支持且仓位会缩小。
- 最近推荐会自动进入下一次稳定性股票池，形成推荐、验证、降权或淘汰的反馈闭环。

### 验证

- Python unittest 共 36 项通过，新增覆盖未来价格不影响历史分类、实时状态映射、稳定匹配加分、状态不匹配阻断、观察降权、失效阻断和未验证标记。
- 真实指数和股票端到端验证中，默认 8 只股票池形成 4 只观察、2 只失效和 2 只样本不足，没有稳定标的。
- 当前震荡环境下的推荐生成读取稳定性批次，实际阻断 3 个候选；保留的未验证候选均标记为低置信并缩小到训练仓位。
- 推荐策略上下文成功写入数据库，HTTP API 返回相同门控统计。
- Vite 生产构建和本地浏览器检查通过；训练推荐证据提示、排行榜历史适用状态显示正常，页面无控制台错误。

## 2026-07-20：多股票滚动样本外验证与稳定性排行榜

### 变更事实

- 新增滚动样本外评估：每个窗口使用此前 180 根日线选择参数，在随后 40 根日线上验证，向前滚动最多 3 次且样本外窗口互不重叠。
- 新增跨窗口聚合指标，包括平均样本外收益、平均基准超额、正收益窗口比例、跑赢基准比例、最差回撤、总交易数、胜率和参数一致性。
- 新增多股票稳定性股票池，默认按当前持仓、自选、最近推荐和高流动性补充的顺序选取最多 8 只股票。
- 新增稳定、观察、失效和样本不足四级门槛；完整交易少于 3 次时不能形成稳定性证据。
- 新增 `strategy_stability_runs` 持久化、最新结果读取接口和 AI 交易页策略稳定性排行榜。

### 行为影响

- 单只股票的一次 70%/30% 通过不再等同于稳定，必须继续接受多个时间窗口和多股票横向比较。
- 排行榜不会因为平均收益为正就自动判定稳定，还会检查基准超额、窗口一致性、回撤和交易样本。
- 页面重新打开时读取最近一次结果，不需要每次重新同步日线并计算。

### 验证

- Python unittest 共 28 项通过，新增覆盖最近 3 个滚动窗口和不足两个样本外窗口的拒绝场景。
- 多股票 API 使用真实日线完成端到端验证，结果成功写入数据库并能从最新记录接口恢复。
- 默认 8 只股票池完成浏览器实际运行，排行榜正确显示 4 只观察和 4 只失效或不足，没有把任何标的误标为跨窗口稳定。
- Vite 生产构建通过；仍只有既有的主 JavaScript 包超过 500 kB 非阻塞提示。
- 本地浏览器页面无控制台错误。

## 2026-07-20：多策略实验室与样本外验证

### 变更事实

- 参考 Qlib 的信号、策略、执行器分层，VectorBT 的批量策略比较与稳健性指标，以及 vn.py 的研究、回测、模拟交易职责分离设计。
- 新增趋势跟随、放量突破和超跌修复三类策略及多组候选参数；参数只在前 70% 时间样本中选择，后 30% 数据保持为样本外验证区间。
- 新增接近 A 股约束的成交模拟：收盘产生信号、下一交易日开盘成交、100 股整手、T+1、最大单票仓位、费用、滑点和不同板块涨跌停阻断。
- 新增收益、基准超额、最大回撤、波动、夏普、交易次数、胜率、盈亏比、费用、持仓暴露和阻断次数等指标，并把实验结果写入 `strategy_experiment_runs`。
- 个股详情的回测页签升级为策略实验室，可比较三类策略的训练期与样本外表现，并明确给出可参考、观察或拒绝结论。
- 修正详情页首次打开时隐藏表单尚未挂载便写入默认值产生的 Ant Design 控制台告警。

### 行为影响

- 系统不再只根据单一策略的一段历史收益判断有效性，可以明确拒绝样本外失效的策略。
- AI 后续分析可直接读取统一的策略实验结果、成交假设和稳健性标签，而不是依赖一次性主观判断。
- 策略通过仍只是研究证据，市场硬风控、组合仓位和行情新鲜度约束继续优先于单股策略结果。

### 验证

- Python unittest 共 26 项通过，新增覆盖次日开盘成交与费用、涨停阻断、三策略时间切分和历史不足场景。
- 使用已同步的 306 根真实日线完成 API 端到端验证，成功生成训练期、样本外区间、基准和三类策略结果并持久化实验记录。
- Vite 生产构建通过；仍只有既有的主 JavaScript 包超过 500 kB 非阻塞提示。
- 本地浏览器完成搜索股票、打开详情、运行策略实验和结果表格检查，页面无控制台错误。

## 2026-07-17：市场硬风控与订单风险约束

### 变更事实

- 新增统一市场风险上下文，在市场极弱、行情过期或数据不足时阻断新增买入。
- AI 推荐从软扣分改为硬风险门控，风险触发时不再输出与市场结论冲突的买入建议。
- 模拟买单在后端校验账户权益、总仓位、单票仓位、当日损失和账户回撤。
- 修正腾讯全市场成交额同步到日线时的万元到元单位换算。
- 后台行情补刷会覆盖推荐列表使用的证券代码。

### 行为影响

- 即使绕过前端直接调用下单接口，买入也会受到统一风险限制。
- 推荐规模依据账户可承受风险计算，减少固定金额和忽略既有持仓造成的冲突。
- 日线成交额不再因数据源单位差异被缩小 10,000 倍。

### 验证

- 新增市场风控、行情金额单位和推荐表现测试，并纳入 22 项完整后端测试集。
- 前端生产构建通过。
